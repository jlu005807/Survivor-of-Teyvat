# Survivor of Teyvat

This project is a small game for learning purposes. You can install and run it via the provided setup package.

## Installation

1. Go to the `Survivor-of-Teyvat_Setup/Release` directory.
2. Double-click `setup.exe` or `Survivor-of-Teyvat_Setup.msi` to install the game.

## How to Run

- After installation, you can find and run the game from the Start Menu or the installation directory.
- All game resources (images, sounds) are included in the installer.

## Project Structure

- `Survivor of Teyvat/`: Source code and resource files
  - `img/`: Game image resources
  - `mus/`: Game sound and music files
  - `*.h`, `main.cpp`: Main source code files
- `Survivor-of-Teyvat_Setup/`: Installer project and generated setup files
- `x64/Debug`, `x64/Release`: Build intermediate files and executables
